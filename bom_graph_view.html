Imagine a bicycle with 2 identical wheels which have 2 nuts each which have 2 nut-washers each. It means you have 2 instances of the assembly "wheel", which contains 2 instances of the assembly "nut", which contains 2 instances of the product "nut-washer". With common PLM software except Siemens Teamcenter and maybe recent graph-based PLM, unique identification of each nut-washer outside the context of the wheel is not natively possible because of the core data model, except if absolute instances of the nut-washer are created by a program in the bicycle context, which is the root product: the absolute positioning system.
